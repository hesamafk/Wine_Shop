# Vine & Vale — Winery Front-End Concept

A responsive static winery storefront concept built with semantic HTML, CSS, and a small amount of vanilla JavaScript.

## Run locally
Open `index.html` directly in a modern browser. No build tools, backend, or package installation are required.

## Included
- Responsive desktop/mobile layout with accessible mobile navigation
- Correct root-level stylesheet reference (`main.css`)
- CSS-drawn hero artwork and bottle mockups, so the page does not depend on missing local image assets
- Clear navigation anchors, contact email link, page title, description, and keyboard skip link

## Important
This is a portfolio UI concept only. It does not provide a real cart, inventory, checkout, payment, or age-verification workflow. The email address is a placeholder and should be replaced before publishing. External Google Fonts require an internet connection; system fallbacks are provided.

## Project files
- `index.html` — page structure and responsive navigation
- `main.css` — styling and responsive breakpoints
